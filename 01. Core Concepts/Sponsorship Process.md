# Sponsorship Process

> [!SUMMARY] Overview
> Provides senior executive ownership, strategic alignment, resource authorization, and benefit advocacy across the life cycle.

## Purpose
The **Sponsorship Process** defines the executive role that links the project or programme to the strategic leadership of the host organization. The Sponsor is the ultimate owner of the [[Business Case]].

## Key Responsibilities
- Champion the vision and secure funding.
- Authorize project initiation, stage boundaries, and closure.
- Set management tolerances for cost, time, and scope.
- Resolve escalated issues from the project manager.
- Ensure organizational change is realized to deliver benefits.
