Quick Introduction

Praxis is a language-independent, community-driven framework for managing and delivering Data Engineering, Analytics, and Business Intelligence initiatives using modern DevOps and DataOps principles. It offers two core workflows:

  • • Declarative (Knowledge & FinOps): Similar to Terraform, Praxis establishes governance baselines against the desired state of data assets. Manage cloud compute budgets (FinOps), data contracts, and organizational context.
  • • Versioned (Method & Medallion): Unlike traditional waterfall guides, Praxis automatically structures schema migrations and pipeline lifecycles across Medallion layers (Bronze, Silver, Gold). Teams can plan, lint, and deploy data pipelines with automated test gates.

Installation

To download and install the latest release of the Praxis P3M CLI, simply run the following in your terminal:

curl -sSf https://praxis-framework.org/install.sh | sh
