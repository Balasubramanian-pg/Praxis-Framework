# Develop Budgets And Control Costs Competency

> [!SUMMARY] Overview
> Demonstrates the capability to estimate expenditures, build time-phased cost baselines, and control project finances.

## Purpose
The **Develop Budgets And Control Costs** competency demonstrates financial rigor in building project budgets and controlling expenditure against approvals.

## Performance Criteria
1. Aggregate cost estimates across work packages to establish the project budget.
2. Establish contingency reserves and management reserves.
3. Track actual commitments, accruals, and cash flow against baseline spend.
4. Forecast final cost-at-completion (EAC) using Earned Value analysis.
