# Exercise Control Competency

> [!SUMMARY] Overview
> Demonstrates the capability to measure actuals, detect variances, assess tolerances, and implement corrective measures.

## Purpose
The **Exercise Control** competency focuses on the active steering of project performance against approved baseline plans.

## Performance Criteria
1. Capture performance data across time, cost, scope, and quality.
2. Compare actual status against baseline tolerances.
3. Determine root causes for variances and forecast future performance.
4. Implement corrective actions or escalate via exception reports when tolerances are breached.
