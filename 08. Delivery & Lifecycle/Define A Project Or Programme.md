# Define A Project Or Programme Competency

> [!SUMMARY] Overview
> Demonstrates the capability to execute the definition process, producing management plans, schedules, and the full business case.

## Purpose
The **Define A Project Or Programme** competency demonstrates an individual's capability to plan an initiative comprehensively, assembling all baselines required for execution.

## Performance Criteria
1. Establish requirements, specifications, and scope breakdown structures.
2. Formulate functional [[Management Plans]] for risk, schedule, finance, and quality.
3. Build integrated delivery schedules and resource budgets.
4. Complete the full [[Business Case]] and secure sponsor authorization.
