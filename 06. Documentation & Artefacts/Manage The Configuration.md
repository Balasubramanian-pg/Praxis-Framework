# Manage The Configuration Competency

> [!SUMMARY] Overview
> Demonstrates the capability to maintain product integrity through identification, status accounting, and verification audits.

## Purpose
The **Manage The Configuration** competency verifies an individual's ability to operate configuration control systems, ensuring deliverable baselines are protected from uncontrolled mutation.

## Performance Criteria
1. Define configuration identification conventions and metadata standards.
2. Record and update configuration item records throughout production.
3. Conduct physical and functional configuration audits before deliverable sign-off.
